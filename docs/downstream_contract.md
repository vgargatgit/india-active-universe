# Downstream contract

Consumers must pin a release ID and manifest hash, then read published artifacts only: `security_master`, `symbol_history`, `issuer_master`, `listing_episodes`, `daily_prices_raw`, `daily_prices_adjusted`, `corporate_actions`, `trading_status`, `active_universe_daily`, `liquidity_features`, and `terminal_events`.

The stable interfaces are `resolve_symbol(symbol, as_of_date)`, `history(security_id, start, end)`, `active_on(as_of_date)`, `eligible_on(as_of_date, ...)`, `ranked_liquid_on(as_of_date, n, metric=...)`, `status_on(as_of_date)`, and `terminal_recovery_scenarios(security_id)`. `DataPlatform.from_release()` reads the published security master and queries Parquet prices, universe, liquidity, and effective-dated status data. Status queries return `ACTIVE_TRADING`, `SUSPENDED`, `DELISTED`, or `UNKNOWN_STATUS` intervals with evidence quality. Recovery scenarios are labelled `ZERO_RECOVERY`, `LAST_OBSERVED_PRICE`, or `DOCUMENTED_VALUE`; they do not overwrite a null canonical terminal value. Use `DataPlatform.from_release(path, strict=True)` to reject dates outside the release coverage; the default is permissive and returns available rows.
