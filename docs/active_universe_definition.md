# Active universe definition

`ACTIVE_V1` is the set of classified ordinary NSE `EQ` securities with a valid qualifying official exchange trading record on date T. Explicit ETFs and other non-ordinary instrument types remain in raw and feature data but are excluded from this ordinary-equity snapshot. It is not an index and is not forced to a fixed count. A row with zero or missing volume remains active when the official record has a valid price, but has `observation_status=NO_TRADE`. Traded rows have `observation_status=TRADED`. Suspended, delisted, no-trade, missing-source, and unknown conditions remain distinguishable.

Investability is downstream-defined. The versioned research profile `LIQUID_V1` requires price >= 20, at least 272 official listing-age sessions, at least 40 positive-volume observations in the trailing 60 official NSE sessions, and 60-session median traded value >= 5,000,000. It is a published consumer profile, not the canonical active universe.

The release API joins PIT liquidity features lazily when reading `active_universe_daily.parquet`. Features include listing age, 20/60/126/252-session traded-value statistics, stale-price counts, and date-level liquidity quintiles. Consumers can call `profile_on(as_of_date, "LIQUID_V1")`, `eligible_on(as_of_date, min_price=..., min_history_sessions=..., min_positive_volume_days_60=..., min_median_traded_value_60=...)`, or `ranked_liquid_on(as_of_date, n, metric=...)`. The default ranking metric is trailing 126-session median traded value. The ranking utility includes only ordinary equities with `ACTIVE_TRADING` status and is not index membership.

Status intervals are separate from active snapshots. `ACTIVE_TRADING` requires an observed qualifying record; `DELISTED` requires linked official evidence; `UNKNOWN_STATUS` means the observation history ended before coverage end and does not imply suspension or zero recovery.
